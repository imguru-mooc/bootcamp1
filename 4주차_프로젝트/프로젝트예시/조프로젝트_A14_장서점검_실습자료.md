## 1. 프로젝트 개요

### 1.1 시나리오

책등에 QR을 붙인 책 8권 이상을 서가(책상 위 북엔드)에 배열합니다. 점검
로봇은 서가를 따라 **이동-정지-스캔**을 반복하며 로봇 거치 폰의
BarcodeDetector로 책 QR을 훑고, 점검이 끝나면 등록 장서 목록과 대조해
**누락 도서, 중복 스캔, 오배열(등록 순서와 다르게 꽂힌 책)**을 찾아 웹
대시보드에 점검 보고서를 표시합니다.

핵심 과제는 주행이 아니라 **스캔 데이터 정합성 처리**입니다: 같은 책이
여러 번 인식되고, 어떤 책은 한 번도 안 잡히는 현실 데이터를 어떻게
신뢰할 수 있는 보고서로 만드는가.

### 1.2 학습 목표

1. 이동-정지-스캔 반복 시퀀스(작업 패턴)를 상태머신으로 구현할 수 있다.
2. 노이즈 낀 스캔 스트림에서 중복 제거·순서 복원을 하는 데이터 정합성 로직을 설계할 수 있다.
3. 기대 목록과 관측 목록의 대조 알고리즘(누락/중복/오배열)을 구현할 수 있다.
4. 인식률을 정량 측정하고 스캔 파라미터(정지 시간·거리)를 근거 있게 정할 수 있다.

### 1.3 시스템 구조

```
〔관리자 폰/PC〕 점검 대시보드 (보고서·진행 현황)
   │ /scan_start (엣지)              ▲ /inventory_report (엣지)
   ▼                                 │
  wss ──── rosbridge_server ─────────┘
   │
   ▼
〔Pi〕 scan_driver (MOVE↔SCAN 반복) ──/cmd_vel(연속)──▶ 터틀봇
        │ /scan_zone (엣지)
        ▼
      inventory_checker (정합성·대조) ◀── /barcode_seen (엣지, 다발)
                                          〔로봇 거치 폰〕 QR 스캐너
```

| /scan_zone | std_msgs/msg/String (JSON) | scan_driver | checker, 스캐너, 대시보드 | 구간 전환 시 | 엣지 | RELIABLE |
| /barcode_seen | std_msgs/msg/String (책ID) | 스캐너 폰 | inventory_checker | 인식 시 | 엣지(다발) | RELIABLE |
| /inventory_report | std_msgs/msg/String (JSON) | inventory_checker | 대시보드 | 점검 완료 시 | 엣지 | RELIABLE |
| /cmd_vel | geometry_msgs/msg/Twist | scan_driver | 터틀봇 | 10Hz | **연속** | RELIABLE |

**/scan_zone JSON**: `{"event": "scan", "segment": 2}` / `{"event": "done"}`
**보고서 JSON**: `{"total_expected": 8, "scanned": 7, "missing": ["B005"], "duplicated": [], "misplaced": ["B003"], "unknown": []}`

> ⚠️ `/barcode_seen`은 같은 책이 초당 여러 번 발행되는 **지저분한
> 스트림**입니다. 이것이 의도된 설계입니다 — 실제 센서 데이터는 원래
> 이렇습니다. 깨끗하게 만드는 책임은 checker에 있습니다(스캐너에서
> 1차 억제 + checker에서 2차 정합성, 이중 방어를 권장).

## 4. 구현 가이드

### 4.1 🧠 QR 스캐너 (scanner.html)

A4/A5의 BarcodeDetector 패턴. 정지 스캔 중 인식 주기 200ms.
같은 코드 연속 인식은 억제하되, **다른 책 사이에 다시 나타나면 발행**
(오배열 검출에 순서 정보가 필요하므로 완전 중복 제거는 금물).

### 4.2 🤖 scan_driver.py (py_compile 검증 완료)

```python
#!/usr/bin/env python3
"""scan_driver: 서가 구간 이동-정지-스캔 반복 시퀀스"""
import json
import rclpy
from rclpy.node import Node
from std_msgs.msg import String
from geometry_msgs.msg import Twist

SEGMENT_SEC = 2.5      # 구간 이동 시간 (실측 보정)
SCAN_SEC = 4.0         # 구간당 스캔 정지 시간
N_SEGMENTS = 4         # 서가 구간 수


class ScanDriver(Node):
    def __init__(self):
        super().__init__('scan_driver')
        self.sub_start = self.create_subscription(String, '/scan_start', self.on_start, 10)
        self.pub_vel = self.create_publisher(Twist, '/cmd_vel', 10)
        self.pub_zone = self.create_publisher(String, '/scan_zone', 10)
        self.phase = 'IDLE'      # IDLE→MOVE→SCAN(반복)→DONE
        self.seg = 0
        self.remain = 0.0
        self.timer = self.create_timer(0.1, self.tick)
        self.get_logger().info('scan_driver 시작')

    def zone_msg(self, text):
        msg = String()
        msg.data = text
        self.pub_zone.publish(msg)       # 엣지: 스캔 웹앱·검사 노드에 통지

    def on_start(self, msg):
        self.seg = 0
        self.phase = 'MOVE'
        self.remain = SEGMENT_SEC
        self.zone_msg(json.dumps({'event': 'start'}))

    def tick(self):
        cmd = Twist()
        if self.phase == 'MOVE':
            cmd.linear.x = 0.08
            self.remain -= 0.1
            if self.remain <= 0:
                self.phase = 'SCAN'
                self.remain = SCAN_SEC
                self.zone_msg(json.dumps({'event': 'scan', 'segment': self.seg}))
        elif self.phase == 'SCAN':
            self.remain -= 0.1           # 정지 스캔 (0,0 발행 유지)
            if self.remain <= 0:
                self.seg += 1
                if self.seg >= N_SEGMENTS:
                    self.phase = 'DONE'
                    self.zone_msg(json.dumps({'event': 'done'}))
                else:
                    self.phase = 'MOVE'
                    self.remain = SEGMENT_SEC
        self.pub_vel.publish(cmd)        # 10Hz 연속


def main():
    rclpy.init()
    node = ScanDriver()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

### 4.3 🤖 inventory_checker.py (py_compile 검증 완료)

```python
#!/usr/bin/env python3
"""inventory_checker: 스캔 결과와 장서 목록 대조 (누락·중복·오배열)"""
import json
import rclpy
from rclpy.node import Node
from std_msgs.msg import String

# 등록 장서: 서가 배열 순서대로 (조가 실제 QR 발급 목록으로 교체)
EXPECTED = ['B001', 'B002', 'B003', 'B004', 'B005', 'B006', 'B007', 'B008']


class InventoryChecker(Node):
    def __init__(self):
        super().__init__('inventory_checker')
        self.scanned = []        # 스캔된 순서 그대로
        self.sub_code = self.create_subscription(String, '/barcode_seen', self.on_code, 10)
        self.sub_zone = self.create_subscription(String, '/scan_zone', self.on_zone, 10)
        self.pub_report = self.create_publisher(String, '/inventory_report', 10)
        self.get_logger().info('inventory_checker 시작')

    def on_code(self, msg):
        """스캔 웹앱의 인식 결과 (중복 발행 가능 → 여기서 정합성 처리)"""
        code = msg.data
        if not self.scanned or self.scanned[-1] != code:   # 연속 중복만 제거
            self.scanned.append(code)

    def on_zone(self, msg):
        d = json.loads(msg.data)
        if d.get('event') == 'done':
            self.report()

    def report(self):
        seen = [c for c in self.scanned if c in EXPECTED]
        unknown = sorted(set(self.scanned) - set(EXPECTED))
        missing = [c for c in EXPECTED if c not in seen]
        duplicated = sorted({c for c in seen if seen.count(c) > 1})
        # 오배열: 스캔 순서가 등록 순서와 다른 책
        uniq_seen = list(dict.fromkeys(seen))
        expected_order = [c for c in EXPECTED if c in uniq_seen]
        misplaced = [c for i, c in enumerate(uniq_seen)
                     if c != expected_order[i]]
        out = String()
        out.data = json.dumps({
            'total_expected': len(EXPECTED), 'scanned': len(uniq_seen),
            'missing': missing, 'duplicated': duplicated,
            'misplaced': misplaced, 'unknown': unknown}, ensure_ascii=False)
        self.pub_report.publish(out)
        self.get_logger().info(f'점검 완료: 누락 {len(missing)}, 오배열 {len(misplaced)}')


def main():
    rclpy.init()
    node = InventoryChecker()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

> ⚠️ **스타터 코드의 알려진 한계(조가 해결할 것)**
> ① 오배열 판정이 "스캔 순서 = 물리 순서"라는 가정에 의존하는데,
> 인접 구간에서 **옆 책이 먼저 잡히면** 정상 배열도 오배열로 나옵니다 —
> 구간(segment) 정보와 결합하거나 판정 로직을 개선하세요. 이 문제를
> 발견·분석하는 것 자체가 이 주제의 핵심 학습입니다. ② 중복 판정
> `duplicated`는 물리적으로 두 권 존재하는 경우와 스캔 노이즈를 구분하지
> 못합니다 — 정의를 조가 정하고 문서화하세요. ③ 점검 재시작 시 `scanned`
> 초기화가 없습니다('start' 이벤트 처리 추가).

### 4.4 🔩 서가·라벨 규격

책 8권+(두께 2cm 이상), QR 라벨 4×4cm 이상을 책등에 같은 높이로 부착.
로봇 거치 폰 렌즈 높이 = 라벨 높이. **스캔 거리(서가-로봇 간격)별
인식률 실험**(10/15/20cm)이 AI 담당의 산출물이자 주행 간격의 근거입니다.
