## 1. 프로젝트 개요

### 1.1 시나리오

모형 차량이 입구에 오면 거치 폰이 차량 QR을 인식해 서보 차단기를 열고
입차를 기록합니다. 3개 주차면의 초음파 센서가 점유 상태를 1Hz로 감지해
관제 대시보드의 실시간 주차 맵과 각 면의 LED 유도등(빈자리 초록)에
반영됩니다. 만차에 가까워지면 안내 로봇이 입구에서 빈 주차면까지
선도 주행으로 차량을 안내합니다.

### 1.2 학습 목표

1. 다중 센서(초음파 ×3)를 하나의 상태 토픽으로 집계할 수 있다.
2. 센서 스트림(연속)과 제어 이벤트(엣지)가 혼재하는 시스템을 설계할 수 있다.
3. 센서값 노이즈에 대한 판정 안정화(디바운스)를 적용할 수 있다.
4. 물리 세계(주차면)와 대시보드 상태의 동기화 문제를 다룰 수 있다.

### 1.3 시스템 구조

```
〔입구 거치 폰〕 QR 인식 웹앱          〔관제 PC/폰〕 주차 맵 대시보드
   │ /entry (엣지)                        ▲ /slot_status(1Hz) /gate_state(엣지)
   ▼                                      │
  wss ──── rosbridge_server ──────────────┘
   │
   ├─▶ gate_node ──▶ 서보 차단기
   ├─▶ slot_monitor(초음파×3) ──▶ /slot_status ──▶ led_node(유도등)
   └─▶ guide_robot ──/cmd_vel(연속)──▶ 터틀봇 (빈 자리 선도)
```

## 3. 토픽 인터페이스 정의서 (INTERFACE.md 초안)

| 토픽명 | 메시지 타입 | 발행자 | 구독자 | 주기 | 성격 | QoS |
|---|---|---|---|---|---|---|
| /entry | std_msgs/msg/String (차량ID) | QR 웹앱 | gate_node, 대장 | 인식 시 | 엣지 | RELIABLE |
| /gate_state | std_msgs/msg/String | gate_node | 대시보드 | 변화 시 | 엣지 | RELIABLE |
| /slot_status | std_msgs/msg/String (JSON) | slot_monitor | 대시보드, led_node, guide_robot | 1Hz | **연속** | RELIABLE |
| /guide_request | std_msgs/msg/String | 대시보드 | guide_robot | 요청 시 | 엣지 | RELIABLE |
| /cmd_vel | geometry_msgs/msg/Twist | guide_robot | 터틀봇 | 10Hz | **연속** | RELIABLE |
| /guide_state | std_msgs/msg/String | guide_robot | 대시보드 | 변화 시 | 엣지 | RELIABLE |

**/slot_status JSON**: `{"1": true, "2": false, "3": false}` (true = 점유)

> ⚠️ `/slot_status`는 1Hz 연속 스트림입니다. 대시보드와 LED는 이 스트림을
> 받아 **변화가 있을 때만** 렌더·점등을 갱신해야 합니다(수신은 연속,
> 반응은 엣지). 이 구분을 놓치면 LED 깜빡임·렌더 낭비가 생깁니다.

계속 보여도 **한 번만** 발행하도록 최근 인식 캐시(5초)를 두세요.

```javascript
const detector = new BarcodeDetector({ formats: ['qr_code'] });
setInterval(async () => {
  const codes = await detector.detect(video);
  for (const c of codes) {
    if (recentlySeen(c.rawValue)) continue;     // 5초 중복 방지
    markSeen(c.rawValue);
    entryTopic.publish(new ROSLIB.Message({ data: c.rawValue }));
  }
}, 300);
```

미지원 시 jsQR 라이브러리로 폴백하는 것까지 하면 Should 가점 요소입니다.

### 4.2 🤖 slot_monitor.py (py_compile 검증 완료)

```python
#!/usr/bin/env python3
"""slot_monitor: 초음파 3개로 주차면 점유 감지 → /slot_status 1Hz"""
import json
import rclpy
from rclpy.node import Node
from std_msgs.msg import String
from gpiozero import DistanceSensor   # export GPIOZERO_PIN_FACTORY=lgpio

# 주차면별 (echo, trigger) 핀 — 배선에 맞게 수정
SLOT_PINS = {1: (24, 23), 2: (8, 25), 3: (16, 12)}
OCCUPIED_M = 0.10     # 10cm 이내 → 점유


class SlotMonitor(Node):
    def __init__(self):
        super().__init__('slot_monitor')
        self.sensors = {sid: DistanceSensor(echo=e, trigger=t, max_distance=1.0)
                        for sid, (e, t) in SLOT_PINS.items()}
        self.pub = self.create_publisher(String, '/slot_status', 10)
        self.timer = self.create_timer(1.0, self.tick)   # 1Hz 연속
        self.get_logger().info('slot_monitor 시작')

    def tick(self):
        status = {str(sid): (s.distance < OCCUPIED_M)
                  for sid, s in self.sensors.items()}
        msg = String()
        msg.data = json.dumps(status)
        self.pub.publish(msg)


def main():
    rclpy.init()
    node = SlotMonitor()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

### 4.3 🔩 gate_node.py (py_compile 검증 완료)

```python
#!/usr/bin/env python3
"""gate_node: 입차 승인 → 서보 차단기 개방 3초 후 폐쇄"""
import rclpy
from rclpy.node import Node
from std_msgs.msg import String
from gpiozero import AngularServo

SERVO_PIN = 18
OPEN_SEC = 3.0


class GateNode(Node):
    def __init__(self):
        super().__init__('gate_node')
        self.servo = AngularServo(SERVO_PIN, min_angle=0, max_angle=90)
        self.servo.angle = 0                       # 닫힘
        self.sub = self.create_subscription(String, '/entry', self.on_entry, 10)
        self.pub_state = self.create_publisher(String, '/gate_state', 10)
        self.close_timer = None
        self.get_logger().info('gate_node 시작')

    def on_entry(self, msg):
        """웹 QR 인식 결과(차량번호) 수신 → 개방 (엣지)"""
        self.servo.angle = 90
        self.publish_state(f'open:{msg.data}')
        if self.close_timer:
            self.close_timer.cancel()
        self.close_timer = self.create_timer(OPEN_SEC, self.close_gate)

    def close_gate(self):
        self.servo.angle = 0
        self.publish_state('closed')
        if self.close_timer:
            self.close_timer.cancel()
            self.close_timer = None

    def publish_state(self, s):
        msg = String()
        msg.data = s
        self.pub_state.publish(msg)


def main():
    rclpy.init()
    node = GateNode()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

### 4.4 🤖 guide_robot / 🔩 led_node

- **guide_robot**: A1의 `table_driver` 패턴을 재사용합니다(테이블 → 주차면).

## 7. 트러블슈팅

| 증상 | 원인 | 해결 |
|---|---|---|
| 점유 상태가 깜빡거림 | 초음파 노이즈 + 디바운스 없음 | 알려진 한계 ① 해결 (3회 연속 판정) |
| 같은 차가 연속 입차 처리됨 | QR 중복 발행 | §4.1 5초 캐시 확인 |
| LED가 1초마다 깜빡임 | 연속 스트림에 매번 재점등 | 변화 감지 후에만 갱신 (§3 ⚠️) |
| 초음파 값이 0 또는 max 고정 | echo/trigger 핀 뒤바뀜 | 배선도 대조, 핀 스왑 |
| 초음파 2개 이상이 서로 간섭 | 동시 트리거 | 측정 순차화(면별 시간차) 또는 물리 간격 확보 |
| 서보가 떨림(지터) | PWM 소프트웨어 한계 | 개폐 후 `servo.detach()` 또는 angle=None |
| 만차인데 차단기가 열림 | S2 미구현 | 승인 계층에서 /slot_status 참조 |
| 대시보드 맵과 실제 불일치 | 접속 시점에 최신 상태 미수신 | 1Hz 연속 스트림이므로 1초 내 자연 동기화 — 그래도 불일치면 slot id 매핑 확인 |
| BarcodeDetector undefined | 미지원 브라우저 | 지원 브라우저 사용 또는 jsQR 폴백 |
