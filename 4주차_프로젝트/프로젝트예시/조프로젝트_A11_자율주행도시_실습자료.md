## 1. 프로젝트 개요

### 1.1 시나리오

바닥 트랙 위를 주행하는 차량(터틀봇)이 로봇 거치 폰 + Teachable
Machine으로 교통표지판(정지/좌회전/속도제한)을 인식해 거동을 바꿉니다.
교차로에는 별도의 **인프라 노드**(LED 신호등)가 있어 주기적으로
빨강/초록을 전환하고 상태를 토픽으로 방송하며, 차량은 교차로 구간에서
적신호면 대기합니다. 차량과 인프라가 토픽으로 협상하는 **V2I(Vehicle-
to-Infrastructure)** 구조이며, 관제 대시보드가 도시 전체 상태를 보여줍니다.

### 1.2 학습 목표

1. 차량과 인프라가 독립 노드로 협상하는 V2I 분산 구조를 설계할 수 있다.
2. 표지판 인식(엣지 이벤트)이 주행 상태머신에 미치는 우선순위를 설계할 수 있다.
3. 직접 학습시킨 분류 모델(Teachable Machine)을 실환경에 배포·평가할 수 있다.
4. 신호등 주기와 차량 거동의 타이밍 상호작용을 검증할 수 있다.

### 1.3 시스템 구조

```
〔관제 PC/폰〕 도시 대시보드 (/vehicle_state /traffic_light 구독)
        ▲
       wss ──── rosbridge_server
        │
        ├──▶ 〔Pi-인프라〕 infra_node ──▶ LED 신호등 (빨강·초록)
        │            └── /traffic_light (엣지)
        ▼
〔Pi-차량〕 vehicle_node ──/cmd_vel(연속)──▶ 터틀봇
        ▲ /sign (엣지)         ▲ /intersection_zone (엣지)
〔로봇 거치 폰〕 표지판 분류 웹앱(TM)   교차로 진입 QR 인식(같은 폰)
```

💡 Pi가 1대뿐이면 인프라 노드도 같은 Pi에서 실행합니다(노드 분리가
핵심이지 하드웨어 분리가 아닙니다).

## 3. 토픽 인터페이스 정의서 (INTERFACE.md 초안)

| 토픽명 | 메시지 타입 | 발행자 | 구독자 | 주기 | 성격 | QoS |
|---|---|---|---|---|---|---|
| /sign | std_msgs/msg/String (JSON) | 분류 웹앱 | vehicle_node | 인식 시 | 엣지 | RELIABLE |
| /intersection_zone | std_msgs/msg/String ("enter"/"exit") | QR 인식(웹) | vehicle_node | 통과 시 | 엣지 | RELIABLE |
| /traffic_light | std_msgs/msg/String ("red"/"green") | infra_node | vehicle_node, 대시보드 | 전환 시 | 엣지 | RELIABLE |
| /vehicle_state | std_msgs/msg/String | vehicle_node | 대시보드 | 변화 시 | 엣지 | RELIABLE |
| /cmd_vel | geometry_msgs/msg/Twist | vehicle_node | 터틀봇 | 10Hz | **연속** | RELIABLE |

**/sign JSON**: `{"label": "정지", "conf": 0.88}` (conf 임계는 웹에서 걸러 발행)

> ⚠️ 교차로 구간 판정은 바닥의 `enter`/`exit` QR 2장으로 합니다.
> "차량이 지금 교차로 접근 중인가"라는 **공간 정보**를 어떻게 얻을지가
> V2I의 실제 난제임을 체험하는 장치입니다. `/traffic_light`는 전환 시에만
> 발행되므로, 차량이 늦게 켜지면 현재 신호를 모릅니다 — 해결책(주기 재방송
> 또는 접속 시 질의)을 조가 설계하세요.

### 4.2 🤖 vehicle_node.py (py_compile 검증 완료)

```python
#!/usr/bin/env python3
"""vehicle_node: 표지판·신호등에 반응하는 차량 상태머신 (V2I)"""
import json, time
import rclpy
from rclpy.node import Node
from std_msgs.msg import String
from geometry_msgs.msg import Twist

CRUISE = 0.10
SLOW = 0.05
STOP_SIGN_SEC = 3.0
SLOW_SEC = 5.0


class VehicleNode(Node):
    def __init__(self):
        super().__init__('vehicle_node')
        self.sub_sign = self.create_subscription(String, '/sign', self.on_sign, 10)
        self.sub_light = self.create_subscription(String, '/traffic_light', self.on_light, 10)
        self.sub_zone = self.create_subscription(String, '/intersection_zone', self.on_zone, 10)
        self.pub_vel = self.create_publisher(Twist, '/cmd_vel', 10)
        self.pub_state = self.create_publisher(String, '/vehicle_state', 10)
        self.light = 'green'
        self.in_intersection = False     # 교차로 접근 구간 여부
        self.stop_until = 0.0            # 정지 표지판 대기
        self.slow_until = 0.0            # 속도제한 구간
        self.turn_route = []             # 좌회전 시퀀스
        self.timer = self.create_timer(0.1, self.tick)
        self.get_logger().info('vehicle_node 시작')

    def set_state(self, s):
        msg = String()
        msg.data = s
        self.pub_state.publish(msg)      # 엣지: 대시보드용

    def on_sign(self, msg):
        """{"label":"정지","conf":0.9} — 신뢰도 임계는 웹에서 처리"""
        d = json.loads(msg.data)
        label = d.get('label')
        if label == '정지':
            self.stop_until = time.time() + STOP_SIGN_SEC
            self.set_state('표지판 정지')
        elif label == '속도제한':
            self.slow_until = time.time() + SLOW_SEC
            self.set_state('서행')
        elif label == '좌회전':
            self.turn_route = [[0.0, 0.5, 3.1], [CRUISE, 0.0, 1.0]]
            self.set_state('좌회전')

    def on_light(self, msg):
        self.light = msg.data            # red / green (인프라 노드 발행)

    def on_zone(self, msg):
        self.in_intersection = (msg.data == 'enter')

    def tick(self):
        now = time.time()
        cmd = Twist()
        if now < self.stop_until:
            pass                          # 표지판 정지
        elif self.in_intersection and self.light == 'red':
            pass                          # 적신호 대기 (V2I 협상)
        elif self.turn_route:
            lx, az, remain = self.turn_route[0]
            cmd.linear.x, cmd.angular.z = float(lx), float(az)
            self.turn_route[0][2] = remain - 0.1
            if self.turn_route[0][2] <= 0:
                self.turn_route.pop(0)
        else:
            cmd.linear.x = SLOW if now < self.slow_until else CRUISE
        self.pub_vel.publish(cmd)         # 10Hz 연속


def main():
    rclpy.init()
    node = VehicleNode()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

### 4.3 🔩 infra_node.py (py_compile 검증 완료)

```python
#!/usr/bin/env python3
"""infra_node: 교차로 신호등 주기 제어 (LED + 상태 방송)"""
import rclpy
from rclpy.node import Node
from std_msgs.msg import String
from gpiozero import LED   # export GPIOZERO_PIN_FACTORY=lgpio

RED_PIN, GREEN_PIN = 17, 27
GREEN_SEC, RED_SEC = 8.0, 6.0


class InfraNode(Node):
    def __init__(self):
        super().__init__('infra_node')
        self.red = LED(RED_PIN)
        self.green = LED(GREEN_PIN)
        self.pub = self.create_publisher(String, '/traffic_light', 10)
        self.state = 'green'
        self.apply()
        self.timer = self.create_timer(GREEN_SEC, self.switch)
        self.get_logger().info('infra_node 시작 (green)')

    def apply(self):
        self.green.value = (self.state == 'green')
        self.red.value = (self.state == 'red')
        msg = String()
        msg.data = self.state
        self.pub.publish(msg)            # 전환 시 엣지 발행

    def switch(self):
        self.timer.cancel()
        self.state = 'red' if self.state == 'green' else 'green'
        self.apply()
        period = RED_SEC if self.state == 'red' else GREEN_SEC
        self.timer = self.create_timer(period, self.switch)


def main():
    rclpy.init()
    node = InfraNode()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

> ⚠️ **스타터 코드의 알려진 한계(조가 해결할 것)**
> ① `/traffic_light`가 전환 시에만 발행되어, 차량 노드가 늦게 시작하면
> **현재 신호를 모른 채 green 기본값으로 통과**합니다 — 주기 재방송(1Hz)
> 또는 latched-like 설계로 개선하세요(§3 ⚠️). ② 정지 표지판 대기 중
> 교차로에 진입해 있으면 두 대기 조건의 우선순위가 모호합니다 — S1 규칙
> 표를 만들어 정책을 명문화하세요. ③ 좌회전 시퀀스 중 적신호가 켜져도
> 회전을 계속합니다 — "교차로 내 차량은 계속 진행"이 실제 교통 규칙과
> 같은지 토론해 결정하세요(좋은 발표 소재입니다).
