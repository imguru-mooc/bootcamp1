## 1. 프로젝트 개요

### 1.1 시나리오

사용자가 로봇 거치 폰 앞에서 간단한 수어 단어(안녕하세요, 감사합니다,
사랑해요, 잘가요, 좋아요 — 5단어 이상)를 표현하면, Hand Landmarker
기반 인식기가 단어를 분류해 **TTS 음성**과 **LCD 자막**으로 통역하고,
로봇이 단어에 어울리는 동작(인사 등)으로 응답합니다.

기술적 도전: 수어는 정지 사진이 아니라 **시간 축이 있는 동작**입니다.
정적 손 모양 판정(Week 2 손가락 개수)을 넘어, 슬라이딩 윈도우 +
시퀀스 매칭으로 "손 모양의 변화 패턴"을 인식하는 것이 AI 파트의 핵심
과제입니다.

> 💡 실제 한국수어(KSL)는 손 모양·위치·방향·움직임·표정이 결합된
> 언어입니다. 이 프로젝트는 교육용 단순화 버전이며, 이 한계를 보고서에
> 명시하는 것까지가 과제입니다.

### 1.2 학습 목표

1. 시계열 제스처 인식(슬라이딩 윈도우, 상태 시퀀스 매칭)을 구현할 수 있다.
2. 프레임 단위 분류와 단어 단위 판정을 분리하는 2단 인식 구조를 설계할 수 있다.
3. 인식 신뢰도·쿨다운으로 연속 입력 스트림에서 이벤트를 안정적으로 추출할 수 있다.
4. 접근성 기술의 가능성과 한계를 실험 기반으로 평가할 수 있다.

### 1.3 시스템 구조

```
〔로봇 거치 폰〕 수어 인식 웹앱
   ├ Hand Landmarker (매 프레임 손 모양 특징)
   ├ 시퀀스 매처 (슬라이딩 윈도우 → 단어 판정)
   └ TTS 재생 (통역 음성)
        │ /sign_word (엣지)        ▲ /tts_text (엣지)
        ▼                          │
  wss ──── rosbridge_server ───────┘
        │
        ▼
〔Pi〕 response_node ──/cmd_vel(연속)──▶ 터틀봇 (인사 동작)
        └─ /lcd_text (엣지) ──▶ LCD (자막)
```

| 토픽명 | 메시지 타입 | 발행자 | 구독자 | 주기 | 성격 | QoS |

> 완료 + 신뢰 임계)은 웹의 책임입니다.

### 4.1 📖 단어 동작 정의 (수어 리서치 담당) — Day 1 최우선

단어 5종의 동작을 손 모양 상태의 **시퀀스로 명세**합니다. 예:

| 단어 | 상태 시퀀스 (예시 단순화) | 동적? |
|---|---|---|
| 안녕하세요 | 펴진 손 → 좌우 흔들기 (x 방향 전환 3회) | ✅ |
| 감사합니다 | 펴진 손이 턱 근처 → 아래로 이동 | ✅ |
| 사랑해요 | 엄지+검지+새끼 펴기 (ILY 유사형) 1초 유지 | 정적 |
| 잘가요 | 손바닥 보이며 손목 상하 접기 2회 | ✅ |
| 좋아요 | 엄지만 펴기 1초 유지 | 정적 |

표현 일관성이 인식률의 절반입니다.

### 4.2 🧠 2단 인식 구조 (AI A + B)

**1단 — 프레임 특징(AI A)**: 매 프레임 손 랜드마크에서 이산 상태 추출.

```javascript
function frameState(lm) {
  const fingers = countExtended(lm);            // Week 2 로직 재사용
  const cx = lm[0].x;                           // 손목 x (이동 추적용)
  return { fingers, cx, ts: performance.now() };
}
```

**2단 — 시퀀스 매칭(AI B)**: 최근 1.5초 윈도우에서 패턴 검사.

```javascript
// 예: '안녕하세요' = 5손가락 유지 + x방향 전환 3회 이상
function matchHello(win) {
  const open = win.filter(f => f.fingers === 5).length / win.length > 0.7;
  let turns = 0, dir = 0;
  for (let i = 1; i < win.length; i++) {
    const d = Math.sign(win[i].cx - win[i-1].cx);
    if (d !== 0 && d !== dir) { turns++; dir = d; }
  }
  return open && turns >= 3;
}
// 단어 확정 시 1회 발행 + 웹 자체 쿨다운
```

S1 실험표(표현자 2인×10회×5단어)가 임계값들의 근거이자 이 주제의
학술적 산출물입니다.

### 4.3 🤖 response_node.py (py_compile 검증 완료)

```python
#!/usr/bin/env python3
"""response_node: 수어 단어 → TTS + LCD 자막 + 인사 동작"""
import time
import rclpy
from rclpy.node import Node
from std_msgs.msg import String
from geometry_msgs.msg import Twist

# 단어 → (음성 문장, 동작 시퀀스[(lx,az,초)])
RESPONSES = {
    '안녕하세요':  ('안녕하세요! 만나서 반가워요.',
                    [(0.0, 0.6, 0.6), (0.0, -0.6, 1.2), (0.0, 0.6, 0.6)]),
    '감사합니다':  ('감사합니다!', [(-0.05, 0.0, 0.6), (0.05, 0.0, 0.6)]),
    '사랑해요':    ('사랑해요!', [(0.0, 1.0, 0.5), (0.0, -1.0, 1.0), (0.0, 1.0, 0.5)]),
    '잘가요':      ('안녕히 가세요!', [(-0.06, 0.0, 1.0)]),
    '좋아요':      ('좋아요!', [(0.0, 0.8, 0.4), (0.0, -0.8, 0.4)]),
}
COOLDOWN = 2.0     # 같은 단어 연속 반응 방지 (초)


class ResponseNode(Node):
    def __init__(self):
        super().__init__('response_node')
        self.sub_word = self.create_subscription(String, '/sign_word', self.on_word, 10)
        self.pub_tts = self.create_publisher(String, '/tts_text', 10)
        self.pub_lcd = self.create_publisher(String, '/lcd_text', 10)
        self.pub_vel = self.create_publisher(Twist, '/cmd_vel', 10)
        self.route = []
        self.last_word = ''
        self.last_ts = 0.0
        self.timer = self.create_timer(0.1, self.tick)
        self.get_logger().info('response_node 시작')

    def on_word(self, msg):
        word = msg.data
        now = time.time()
        if word not in RESPONSES:
            return
        if word == self.last_word and now - self.last_ts < COOLDOWN:
            return                        # 쿨다운
        self.last_word, self.last_ts = word, now
        speech, seq = RESPONSES[word]
        tts = String(); tts.data = speech
        self.pub_tts.publish(tts)         # 웹 TTS 재생 (엣지)
        lcd = String(); lcd.data = word
        self.pub_lcd.publish(lcd)         # 자막 (엣지)
        self.route = [list(s) for s in seq]

    def tick(self):
        cmd = Twist()
        if self.route:
            lx, az, remain = self.route[0]
            cmd.linear.x, cmd.angular.z = float(lx), float(az)
            self.route[0][2] = remain - 0.1
            if self.route[0][2] <= 0:
                self.route.pop(0)
        self.pub_vel.publish(cmd)         # 10Hz 연속


def main():
    rclpy.init()
    node = ResponseNode()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

> ⚠️ **스타터 코드의 알려진 한계(조가 해결할 것)**
> ① 쿨다운이 **같은 단어만** 막습니다 — 동작 중 다른 단어가 인식되면
> 동작이 교체됩니다. 응답 중 신규 단어 정책(대기열? 무시? 교체?)을
> 정하세요. ② TTS가 A12처럼 사용자 제스처 활성화가 필요합니다.
> ③ 동적 단어끼리(안녕하세요 ↔ 잘가요)의 혼동은 시퀀스 매칭의 진짜
> 난제입니다 — S1 실험에서 혼동 쌍을 찾아내고 특징을 추가해 분리하는
> 반복이 이 주제의 핵심 사이클입니다.
