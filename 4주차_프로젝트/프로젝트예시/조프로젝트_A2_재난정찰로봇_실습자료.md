## 1. 프로젝트 개요

### 1.1 시나리오

조종자는 현장이 보이지 않는 위치(칸막이 뒤)에서 로봇 거치 폰의 FPV 영상만
보며 자신의 폰 기울임으로 로봇을 원격 조종합니다. 영상에서 사람이 탐지되면
로봇은 조종 입력과 무관하게 자동 정지하고 이벤트를 기록하며, 주행 중
측정한 환경값(조도·온도)은 관제 대시보드에 실시간 그래프로 표시됩니다.

### 1.2 학습 목표

1. 폰 IMU(DeviceOrientation)를 아날로그 조종 입력으로 매핑할 수 있다.
2. 안전 정지가 조종 명령보다 우선하는 **명령 중재 구조**를 설계할 수 있다.
3. 영상 지연이 있는 원격 조종의 한계와 대응(속도 제한)을 체감한다.
4. 센서 스트림(1Hz 연속)과 이벤트(엣지)를 구분해 대시보드에 표시할 수 있다.

### 1.3 시스템 구조

```
〔조종 폰〕 기울임 조종 웹앱          〔관제 PC/폰〕 대시보드 (그래프+이벤트)
   │ /joy_cmd (JSON, 연속)               ▲ /env_data(1Hz) /event(엣지)
   ▼                                     │
  wss ──── rosbridge_server ─────────────┘
   │
   ▼
〔Pi〕 safety_supervisor ──/cmd_vel(10Hz 연속)──▶ 터틀봇
   ▲            env_sensor_node(ADS7830) ──▶ /env_data
   │ /detection (엣지)
〔로봇 거치 폰〕 FPV + Object Detector(사람 탐지) 웹앱
```

## 3. 토픽 인터페이스 정의서 (INTERFACE.md 초안)

| 토픽명 | 메시지 타입 | 발행자 | 구독자 | 주기 | 성격 | QoS |
|---|---|---|---|---|---|---|
| /joy_cmd | std_msgs/msg/String (JSON) | 조종 웹앱 | safety_supervisor | 10Hz | **연속** | RELIABLE |
| /detection | std_msgs/msg/Bool | FPV 웹앱 | safety_supervisor | 상태 변화 시 | 엣지 | RELIABLE |
| /cmd_vel | geometry_msgs/msg/Twist | safety_supervisor | 터틀봇 | 10Hz | **연속** | RELIABLE |
| /event | std_msgs/msg/String (JSON) | safety_supervisor | 대시보드 | 탐지 시 | 엣지 | RELIABLE |
| /env_data | std_msgs/msg/String (JSON) | env_sensor_node | 대시보드 | 1Hz | **연속** | RELIABLE |

**조종 JSON**: `{"lx": 0.08, "az": -0.3}` (기울기 → 속도 매핑 결과)
**이벤트 JSON**: `{"type": "person", "ts": 1720240512.3}`

> ⚠️ `/joy_cmd`는 이 과정에서 처음 등장하는 **웹 발신 연속 토픽**입니다.
> 10Hz로 계속 발행해야 하며, supervisor는 0.5초 수신이 없으면 정지합니다.
> 이것이 조종 폰이 꺼졌을 때의 1차 안전장치입니다.

## 4. 구현 가이드

### 4.1 🌐 기울임 조종 웹앱 (joy.html)

iOS는 센서 사용 전 명시적 권한 요청이 필요합니다(HTTPS 필수 — GitHub Pages라 충족).

```javascript
// 권한 요청 (버튼 클릭 핸들러 안에서 — iOS 요구사항)
if (DeviceOrientationEvent.requestPermission)
  await DeviceOrientationEvent.requestPermission();

window.addEventListener('deviceorientation', (e) => {
  // beta: 앞뒤 기울기(-180~180), gamma: 좌우(-90~90)
  pitch = e.beta; roll = e.gamma;
});

// 10Hz 연속 발행 + 데드존
setInterval(() => {
  const lx = Math.abs(pitch) < 10 ? 0 : clamp(-(pitch - 10) / 300, -0.12, 0.12);
  const az = Math.abs(roll) < 10 ? 0 : clamp(-roll / 90, -0.6, 0.6);
  joyTopic.publish(new ROSLIB.Message({ data: JSON.stringify({ lx, az }) }));
}, 100);
```

요구 UI: 현재 기울기·속도 게이지, 비상 정지 버튼(누르면 {0,0} 발행 유지).

### 4.2 🧠 FPV + 사람 탐지 웹앱 (fpv.html) — 로봇 거치 폰

MediaPipe **Object Detector**(EfficientDet-Lite0)를 사용해 `person`
카테고리만 필터링합니다. 탐지 상태가 **바뀔 때만** `/detection`을
발행합니다(디바운스 8프레임, 1일차 문서 §9.1 패턴).

```javascript
const persons = result.detections.filter(
  d => d.categories[0].categoryName === 'person' && d.categories[0].score > 0.5);
publishOnChange(persons.length > 0);   // 엣지 발행
```

💡 FPV 영상은 이 폰 화면을 화상회의 앱/미러링으로 조종자에게 보여주는
방식이 가장 간단합니다(WebRTC 직접 구현은 Could 수준). AI 담당은
거리·조명별 탐지율 표를 작성해 보고서에 첨부하세요.

### 4.3 🤖 safety_supervisor.py (py_compile 검증 완료)

```python
#!/usr/bin/env python3
"""safety_supervisor: 폰 기울임 조종 + 사람 감지 자동 정지 중재"""
import json, time
import rclpy
from rclpy.node import Node
from std_msgs.msg import String, Bool
from geometry_msgs.msg import Twist

JOY_TIMEOUT = 0.5     # 조종 입력 소실 시 정지 (초)
HOLD_STOP = 3.0       # 사람 감지 시 정지 유지 (초)


class SafetySupervisor(Node):
    def __init__(self):
        super().__init__('safety_supervisor')
        self.sub_joy = self.create_subscription(String, '/joy_cmd', self.on_joy, 10)
        self.sub_det = self.create_subscription(Bool, '/detection', self.on_detect, 10)
        self.pub_vel = self.create_publisher(Twist, '/cmd_vel', 10)
        self.pub_event = self.create_publisher(String, '/event', 10)
        self.joy = {'lx': 0.0, 'az': 0.0}
        self.last_joy = 0.0
        self.stop_until = 0.0
        self.timer = self.create_timer(0.1, self.tick)   # 10Hz 연속 발행
        self.get_logger().info('safety_supervisor 시작')

    def on_joy(self, msg):
        try:
            self.joy = json.loads(msg.data)
            self.last_joy = time.time()
        except json.JSONDecodeError:
            pass

    def on_detect(self, msg):
        """사람 감지(엣지) → 자동 정지 + 이벤트 기록"""
        if msg.data:
            self.stop_until = time.time() + HOLD_STOP
            ev = String()
            ev.data = json.dumps({'type': 'person', 'ts': time.time()})
            self.pub_event.publish(ev)
            self.get_logger().info('사람 감지 → 자동 정지')

    def tick(self):
        cmd = Twist()
        now = time.time()
        joy_alive = (now - self.last_joy) < JOY_TIMEOUT
        if now >= self.stop_until and joy_alive:      # 안전 정지가 조종보다 우선
            cmd.linear.x = float(self.joy.get('lx', 0.0))
            cmd.angular.z = float(self.joy.get('az', 0.0))
        self.pub_vel.publish(cmd)


def main():
    rclpy.init()
    node = SafetySupervisor()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

### 4.4 🔩 env_sensor_node.py (py_compile 검증 완료)

```python
#!/usr/bin/env python3
"""env_sensor_node: ADS7830으로 조도·온도 측정 → /env_data 1Hz 발행"""
import json
import rclpy
from rclpy.node import Node
from std_msgs.msg import String
from smbus2 import SMBus

ADDR = 0x48
CH_LIGHT, CH_TEMP = 0, 1


def read_adc(bus, chn):
    cmd = 0x84 | (((chn << 2 | chn >> 1) & 0x07) << 4)
    bus.write_byte(ADDR, cmd)
    return bus.read_byte(ADDR)


class EnvSensor(Node):
    def __init__(self):
        super().__init__('env_sensor_node')
        self.bus = SMBus(1)
        self.pub = self.create_publisher(String, '/env_data', 10)
        self.timer = self.create_timer(1.0, self.tick)   # 1Hz 연속
        self.get_logger().info('env_sensor_node 시작')

    def tick(self):
        light = read_adc(self.bus, CH_LIGHT)
        temp_raw = read_adc(self.bus, CH_TEMP)
        msg = String()
        msg.data = json.dumps({'light': light, 'temp_raw': temp_raw})
        self.pub.publish(msg)


def main():
    rclpy.init()
    node = EnvSensor()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

## 7. 트러블슈팅

| 증상 | 원인 | 해결 |
|---|---|---|
| iOS에서 기울임 값이 안 들어옴 | 센서 권한 미요청 | 버튼 클릭 핸들러 안에서 requestPermission 호출 |

| 사람이 보이는데 3초 후 재출발 | 알려진 한계 ② | 탐지 유지 중 정지 지속 설계 |
| 정지 해제 시 급출발 | 알려진 한계 ① | S2 램프업 구현 |
| 그래프가 안 그려짐 | /env_data 파싱 실패 | JSON 키 확인, `topic echo`로 원본 검증 |
| I2C 읽기 오류 | I2C 비활성/주소 오류 | config.txt 활성화, `i2cdetect -y 1` |
| FPV 지연으로 벽 충돌 | 지연 대비 속도 과다 | 최대 속도 0.08 이하로 제한 (S3) |
