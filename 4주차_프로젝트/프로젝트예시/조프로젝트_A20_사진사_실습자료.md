## 1. 프로젝트 개요

### 1.1 시나리오

로봇 거치 폰이 얼굴·포즈를 인식해 인물의 위치와 크기를 파악하고,
로봇이 스스로 회전·전후진하며 인물이 프레임의 목표 지점(중앙 또는
3분할점)에 알맞은 크기로 오도록 **구도를 잡습니다**. 구도가 완성되면
TTS로 "좋아요! 그대로 웃어주세요"라고 안내하고, **전원이 웃는 표정**을
1.5초 유지하면 자동 촬영해 웹 갤러리에 업로드합니다. "왼쪽으로 한 걸음
가주세요" 같은 포즈 가이드까지 넣으면 시연 재미가 확실한 주제입니다.

### 1.2 학습 목표

1. 시각 피드백(인물 위치·크기) 기반 2축 P 제어(회전+전후진)를 구현할 수 있다.
2. 조건 유지 판정(스마일 1.5초 유지)과 쿨다운으로 이벤트를 안정적으로 트리거할 수 있다.
3. 구도 규칙(중앙/3분할)을 제어 목표로 수치화할 수 있다.
4. 촬영 결과물을 수집·전시하는 갤러리 파이프라인을 만들 수 있다.

### 1.3 시스템 구조

```
〔로봇 거치 폰〕 인식+촬영 웹앱
   ├ Face/Pose: /subject {cx,size} (연속 10Hz)
   ├ 표정: /all_smiling (Bool, 상태 변화 시)
   └ /shoot 수신 → 캔버스 캡처 → 갤러리 업로드(/photo)
        │
       wss ──── rosbridge_server ───▶ 〔전시 폰/PC〕 갤러리 웹앱 (/photo 구독)
        │
        ▼
〔Pi〕 framing_node ──/cmd_vel(연속)──▶ 터틀봇 (구도 잡기)
        └─ /tts_text (엣지: 포즈 가이드) ──▶ 웹 TTS
```

## 4. 구현 가이드

### 4.1 🧠 인물 위치·크기 + 전원 미소

- **cx·size**: Face Detector 결과의 바운딩박스에서 산출. 다인 시 정책
  (§3 ⚠️)에 따라 결합. 320px 처리 해상도로 10Hz 유지.
- **all_smiling**: 얼굴별 blendshape `mouthSmile` 평균 > 0.5의 AND 결합
  → 상태 변화 시만 발행(디바운스 8프레임). AI B의 실험: 인원수(1/2/3명)별
  전원 미소 판정 성공률.

### 4.2 🤖 framing_node.py (py_compile 검증 완료)

```python
#!/usr/bin/env python3
"""framing_node: 인물 구도 잡기 (회전+전후진) → 전원 미소 시 촬영 신호"""
import time
import rclpy
from rclpy.node import Node
from std_msgs.msg import String, Bool, Float32
from geometry_msgs.msg import Twist

CX_TARGET = 0.5        # 인물 중심 목표 (화면 가로 비율; 3분할이면 0.33/0.67)
CX_DEADBAND = 0.06
SIZE_TARGET = 0.5      # 인물 크기 목표 (화면 높이 비율)
SIZE_DEADBAND = 0.06
GAIN_ANG = 1.2
GAIN_LIN = 0.5
SUBJ_TIMEOUT = 1.0
SMILE_HOLD = 1.5       # 전원 미소 유지 시간 → 촬영
SHOOT_COOLDOWN = 5.0


class FramingNode(Node):
    def __init__(self):
        super().__init__('framing_node')
        self.sub_subj = self.create_subscription(String, '/subject', self.on_subject, 10)
        self.sub_smile = self.create_subscription(Bool, '/all_smiling', self.on_smile, 10)
        self.pub_vel = self.create_publisher(Twist, '/cmd_vel', 10)
        self.pub_shoot = self.create_publisher(Bool, '/shoot', 10)
        self.pub_tts = self.create_publisher(String, '/tts_text', 10)
        self.cx = 0.5
        self.size = 0.0
        self.last_subj = 0.0
        self.smiling_since = None
        self.last_shot = 0.0
        self.framed_said = False
        self.timer = self.create_timer(0.1, self.tick)
        self.get_logger().info('framing_node 시작')

    def say(self, text):
        msg = String()
        msg.data = text
        self.pub_tts.publish(msg)         # 엣지

    def on_subject(self, msg):
        """웹: {"cx":0.42,"size":0.38} (연속 10Hz)"""
        import json
        d = json.loads(msg.data)
        self.cx = float(d.get('cx', 0.5))
        self.size = float(d.get('size', 0.0))
        self.last_subj = time.time()

    def on_smile(self, msg):
        if msg.data and self.smiling_since is None:
            self.smiling_since = time.time()
        elif not msg.data:
            self.smiling_since = None

    def framed(self):
        return (abs(self.cx - CX_TARGET) < CX_DEADBAND and
                abs(self.size - SIZE_TARGET) < SIZE_DEADBAND)

    def tick(self):
        now = time.time()
        cmd = Twist()
        alive = (now - self.last_subj) < SUBJ_TIMEOUT
        if alive and not self.framed():
            err_x = self.cx - CX_TARGET
            if abs(err_x) > CX_DEADBAND:
                cmd.angular.z = float(-GAIN_ANG * err_x)   # 중심 맞추기
            err_s = self.size - SIZE_TARGET
            if abs(err_s) > SIZE_DEADBAND:
                cmd.linear.x = float(-GAIN_LIN * err_s)    # 크기 맞추기
            self.framed_said = False
        elif alive and self.framed() and not self.framed_said:
            self.framed_said = True
            self.say('좋아요! 그대로 웃어주세요.')
        self.pub_vel.publish(cmd)                          # 10Hz 연속
        # 촬영 판정: 구도 완성 + 전원 미소 유지 + 쿨다운
        if (alive and self.framed() and self.smiling_since and
                now - self.smiling_since > SMILE_HOLD and
                now - self.last_shot > SHOOT_COOLDOWN):
            self.last_shot = now
            self.smiling_since = None
            shoot = Bool(); shoot.data = True
            self.pub_shoot.publish(shoot)                  # 엣지: 웹이 촬영
            self.say('찰칵! 촬영했습니다.')


def main():
    rclpy.init()
    node = FramingNode()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

> ⚠️ **스타터 코드의 알려진 한계(조가 해결할 것)**
> ① framed 경계에서 로봇이 미세 진동하며 구도 완성↔미완성을 오갈 수
> 있습니다(히스테리시스 없음) — "완성 판정은 좁게, 해제 판정은 넓게"의
> 이중 데드밴드로 개선하세요(A7 카운팅과 같은 원리입니다). ② 포즈
> 가이드(S2)가 없습니다 — err_x 부호로 "왼쪽/오른쪽으로 한 걸음"을
> 말하게 하는 것이 S2 과제입니다(단, 로봇이 스스로 도는 것과 사람을
> 움직이게 하는 것의 역할 분담을 설계하세요: 크기는 사람에게, 중심은
> 로봇이 — 같은 정책이 좋은 토론거리). ③ 촬영 순간 로봇이 완전
> 정지한다는 보장이 없습니다 — 촬영 직전 0.3초 정지 유지 조건을
> 추가하면 흔들림 없는 사진이 나옵니다.
