## 1. 프로젝트 개요

### 1.1 시나리오

로봇이 정해진 경로를 자율 순찰합니다. 로봇 거치 폰이 사람을 감지하면
즉시 정지(경보 상태)하고 스냅샷을 캡처해 보호자 대시보드의 이벤트
타임라인에 기록하며 LED 경광과 부저로 현장 경고를 냅니다. 보호자는
대시보드에서 수동 조종 모드로 전환해 현장을 확인한 뒤 순찰을 재개시킵니다.

### 1.2 학습 목표

1. 자율(PATROL) ↔ 수동(MANUAL) ↔ 경보(ALERT) **상태머신**을 설계할 수 있다.
2. 상태별로 `/cmd_vel`의 결정 주체가 바뀌는 모드 중재를 구현할 수 있다.
3. 이벤트(엣지)와 스냅샷을 결합한 타임라인 UI를 만들 수 있다.
4. 반복 순찰 경로의 누적 오차를 측정하고 보정 전략을 세울 수 있다.

### 1.3 시스템 구조

```
〔보호자 폰/PC〕 대시보드 (타임라인 + 모드 전환 + 수동 조이스틱)
   │ /mode, /manual_cmd(연속)          ▲ /event, /patrol_state (엣지)
   ▼                                   │
  wss ──── rosbridge_server ───────────┘
   │
   ▼
〔Pi〕 patrol_node (상태머신) ──/cmd_vel(10Hz 연속)──▶ 터틀봇
   ▲                └─/event──▶ 대시보드   LED·부저 노드 ◀─/alert(엣지)
   │ /detection (엣지)
〔로봇 거치 폰〕 사람 감지 + 스냅샷 웹앱
```

### 4.3 🤖 patrol_node.py (py_compile 검증 완료)

```python
#!/usr/bin/env python3
"""patrol_node: 자율 순찰 ↔ 수동 조종 ↔ 경보 상태머신"""
import json, time
import rclpy
from rclpy.node import Node
from std_msgs.msg import String, Bool
from geometry_msgs.msg import Twist

# 순찰 경로: (lx, az, 초) — 실측 보정 필요
PATROL_ROUTE = [(0.10, 0.0, 4.0), (0.0, 0.5, 3.1),
                (0.10, 0.0, 4.0), (0.0, 0.5, 3.1)]
MANUAL_TIMEOUT = 0.5


class PatrolNode(Node):
    def __init__(self):
        super().__init__('patrol_node')
        self.sub_mode = self.create_subscription(String, '/mode', self.on_mode, 10)
        self.sub_manual = self.create_subscription(String, '/manual_cmd', self.on_manual, 10)
        self.sub_det = self.create_subscription(Bool, '/detection', self.on_detect, 10)
        self.pub_vel = self.create_publisher(Twist, '/cmd_vel', 10)
        self.pub_event = self.create_publisher(String, '/event', 10)
        self.pub_state = self.create_publisher(String, '/patrol_state', 10)
        self.state = 'PATROL'            # PATROL / MANUAL / ALERT
        self.route = []
        self.manual = {'lx': 0.0, 'az': 0.0}
        self.last_manual = 0.0
        self.timer = self.create_timer(0.1, self.tick)
        self.get_logger().info('patrol_node 시작 (PATROL)')

    def set_state(self, s):
        if s != self.state:
            self.state = s
            msg = String()
            msg.data = s
            self.pub_state.publish(msg)   # 엣지: 변화 시에만

    def on_mode(self, msg):
        if msg.data in ('patrol', 'manual'):
            self.set_state('PATROL' if msg.data == 'patrol' else 'MANUAL')
            self.route = []

    def on_manual(self, msg):
        try:
            self.manual = json.loads(msg.data)
            self.last_manual = time.time()
        except json.JSONDecodeError:
            pass

    def on_detect(self, msg):
        if msg.data and self.state == 'PATROL':
            self.set_state('ALERT')       # 정지 + 이벤트, 보호자 조치 대기
            ev = String()
            ev.data = json.dumps({'type': 'intruder', 'ts': time.time()})
            self.pub_event.publish(ev)

    def tick(self):
        cmd = Twist()
        if self.state == 'PATROL':
            if not self.route:
                self.route = [list(s) for s in PATROL_ROUTE]   # 경로 반복
            lx, az, remain = self.route[0]
            cmd.linear.x, cmd.angular.z = float(lx), float(az)
            self.route[0][2] = remain - 0.1
            if self.route[0][2] <= 0:
                self.route.pop(0)
        elif self.state == 'MANUAL':
            if (time.time() - self.last_manual) < MANUAL_TIMEOUT:
                cmd.linear.x = float(self.manual.get('lx', 0.0))
                cmd.angular.z = float(self.manual.get('az', 0.0))
        # ALERT: 정지 유지 (0,0)
        self.pub_vel.publish(cmd)


def main():
    rclpy.init()
    node = PatrolNode()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```
