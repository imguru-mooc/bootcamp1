## 1. 프로젝트 개요

### 1.1 시나리오

로봇이 교실 일부(3×4 격자)를 지그재그로 순회하며 각 셀에 정지해
ADS7830으로 조도·온도를 측정하고, 셀 좌표와 함께 기록합니다. 웹
대시보드는 수신한 데이터를 **Canvas 색상 히트맵**으로 렌더링합니다.
"에어컨 아래가 실제로 몇 도 낮은가", "창가 조도는 안쪽의 몇 배인가" —
느낌이 아니라 **데이터로 답하는** 프로젝트입니다.

핵심 과제 두 가지: ① 측정값과 측정 위치의 동기화(로봇이 어느 셀에
있는지 어떻게 아는가 — 데드레코닝의 신뢰 문제), ② 원시 데이터를 읽을
수 있는 시각화로 만드는 것.

### 1.2 학습 목표

1. 격자 순회(serpentine) 경로를 생성·실행하는 커버리지 패턴을 구현할 수 있다.
2. 측정-위치 동기화 문제를 이해하고 오차를 평가할 수 있다.
3. 센서 원시값 캘리브레이션(온도 raw→°C)과 측정 반복성 실험을 수행할 수 있다.
4. Canvas로 수치 데이터를 색상 히트맵으로 시각화하고 해석할 수 있다.

### 1.3 시스템 구조

```
〔관제 폰/PC〕 히트맵 대시보드 (Canvas)
   │ /survey_start (엣지)          ▲ /cell_data (셀당 1회 엣지)
   ▼                               │
  wss ──── rosbridge_server ───────┘
   │
   ▼
〔Pi〕 grid_survey ──/cmd_vel(10Hz 연속)──▶ 터틀봇 (3×4 지그재그)
        └─ ADS7830 (조도 CH0, 온도 CH1) — 셀 정지 시 측정
```

| 역할 | 담당 | 핵심 산출물 |
|---|---|---|

> ⚠️ 이 프로젝트의 측정 위치는 **"몇 초 이동했으니 그 셀일 것"이라는

> 셀 데이터가 실제로는 (2,2) 위치에서 측정된 것일 수 있습니다. S3
> 오차 평가(마지막 셀 실측)로 이 가정의 신뢰 한계를 정량화하세요 —
> A16(경로 재현)과 같은 근본 문제를 측정의 관점에서 만납니다.

## 4. 구현 가이드

### 4.1 🤖 grid_survey.py (py_compile 검증 완료)

```python
#!/usr/bin/env python3
"""grid_survey: 격자 순회(지그재그) + 지점별 조도·온도 측정 기록"""
import json
import rclpy
from rclpy.node import Node
from std_msgs.msg import String
from geometry_msgs.msg import Twist
from smbus2 import SMBus

ROWS, COLS = 3, 4          # 격자 크기
CELL_SEC = 3.0             # 셀 간 이동 시간 (실측 보정)
TURN_SEC = 3.1             # 90도 회전 시간
MEASURE_SEC = 2.0          # 셀 측정 정지 시간
ADDR = 0x48
CH_LIGHT, CH_TEMP = 0, 1


def read_adc(bus, chn):
    cmd = 0x84 | (((chn << 2 | chn >> 1) & 0x07) << 4)
    bus.write_byte(ADDR, cmd)
    return bus.read_byte(ADDR)


def build_route():
    """지그재그(serpentine) 경로: 셀 이동/회전 스텝 목록 생성"""
    steps = []   # ('move', sec) / ('turnL'|'turnR', sec) / ('cell', r, c)
    for r in range(ROWS):
        cols = range(COLS) if r % 2 == 0 else range(COLS - 1, -1, -1)
        for i, c in enumerate(cols):
            steps.append(('cell', r, c))
            if i < COLS - 1:
                steps.append(('move', CELL_SEC))
        if r < ROWS - 1:                     # 다음 행으로 U턴
            turn = 'turnL' if r % 2 == 0 else 'turnR'
            steps.append((turn, TURN_SEC))
            steps.append(('move', CELL_SEC))
            steps.append((turn, TURN_SEC))
    return steps


class GridSurvey(Node):
    def __init__(self):
        super().__init__('grid_survey')
        self.bus = SMBus(1)
        self.sub_start = self.create_subscription(String, '/survey_start', self.on_start, 10)
        self.pub_vel = self.create_publisher(Twist, '/cmd_vel', 10)
        self.pub_cell = self.create_publisher(String, '/cell_data', 10)
        self.steps = []
        self.remain = 0.0
        self.measuring_cell = None
        self.timer = self.create_timer(0.1, self.tick)
        self.get_logger().info('grid_survey 시작')

    def on_start(self, msg):
        self.steps = list(build_route())
        self.get_logger().info(f'{ROWS}x{COLS} 격자 순회 시작 ({len(self.steps)}스텝)')

    def measure(self, r, c):
        data = {'row': r, 'col': c,
                'light': read_adc(self.bus, CH_LIGHT),
                'temp_raw': read_adc(self.bus, CH_TEMP)}
        msg = String()
        msg.data = json.dumps(data)
        self.pub_cell.publish(msg)          # 엣지: 셀당 1회
        self.get_logger().info(f'({r},{c}) 측정 완료')

    def tick(self):
        cmd = Twist()
        if self.steps:
            step = self.steps[0]
            if step[0] == 'cell':
                if self.measuring_cell is None:      # 측정 시작
                    self.measuring_cell = step
                    self.remain = MEASURE_SEC
                self.remain -= 0.1
                if self.remain <= 0:                 # 측정 완료 → 발행
                    self.measure(step[1], step[2])
                    self.measuring_cell = None
                    self.steps.pop(0)
            else:
                kind, sec = step[0], step[1]
                if self.remain <= 0:
                    self.remain = sec
                if kind == 'move':
                    cmd.linear.x = 0.08
                elif kind == 'turnL':
                    cmd.angular.z = 0.5
                elif kind == 'turnR':
                    cmd.angular.z = -0.5
                self.remain -= 0.1
                if self.remain <= 0:
                    self.steps.pop(0)
        self.pub_vel.publish(cmd)            # 10Hz 연속


def main():
    rclpy.init()
    node = GridSurvey()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

> ⚠️ **스타터 코드의 알려진 한계(조가 해결할 것)**
> ① 측정이 **1회 샘플**입니다 — ADC 노이즈가 그대로 히트맵에 박힙니다.
> MEASURE_SEC 동안 N회 샘플의 평균/중앙값으로 개선하세요(M5 반복성
> 실험과 연결). ② 회전 누적 오차로 뒷 행일수록 격자에서 밀립니다 —
> S3 오차 평가로 정량화하고, 필요하면 행 전환 후 보정 스텝을 넣으세요.
> ③ 순회 중단·재개가 없습니다 — 12셀 완주 실패 시 처음부터라는
> 운영상 부담을 어떻게 다룰지 조가 결정하세요.

### 4.2 🌐 히트맵 렌더링 (heatmap.html)

```javascript
cellTopic.subscribe((msg) => {
  const d = JSON.parse(msg.data);
  grid[d.row][d.col] = d;
  drawHeatmap();
});
function colorFor(v, min, max) {          // 파랑(저) → 빨강(고)
  const t = (v - min) / (max - min || 1);
  return `hsl(${240 - 240 * t}, 85%, 55%)`;
}
```

색상 스케일의 min/max를 고정할지(측정마다 색이 안정) 동적으로 할지
(대비가 극대화)는 시각화 설계 결정입니다 — 둘을 비교해 보고서에 쓰면
좋은 소재가 됩니다. 셀에는 수치도 함께 표기하세요(색만으로는 오독).

### 4.3 🔩 온도 캘리브레이션 (M4)

기준 온도계로 저온(창가/얼음물 근처 공기)과 고온(히터 근처) 2점에서
raw값을 기록 → 선형 변환식 도출 → 표로 제시. 조도는 raw 그대로
상대값으로 써도 되지만 "밝음/어둠 기준 raw" 앵커 2점은 기록하세요.
