## 1. 프로젝트 개요

### 1.1 시나리오

**"초등학생용 제품"**을 가정합니다. 아이는 폰/태블릿 웹앱에서 블록
(앞으로 3초 / 왼쪽으로 / 부저 / 기다리기)을 조립해 프로그램을 만들고,
실행 버튼을 누르면 로봇이 그 시퀀스를 수행합니다. 실행 중에는 현재
실행 블록이 하이라이트되고, 초음파로 장애물이 감지되면 **안전
중단**됩니다. 최종일에는 타 조원이 "아이 역할"로 참여하는 실제 사용자
테스트를 하고 UX 개선점을 기록합니다.

### 1.2 학습 목표

1. 프로그램(데이터)과 실행기(인터프리터)를 분리하는 구조를 설계할 수 있다.
2. 블록 시퀀스를 안전 조건과 함께 해석·실행하는 인터프리터 노드를 만들 수 있다.
3. 실행 상태(현재 블록·중단 사유)를 UI에 역전파하는 양방향 흐름을 구현할 수 있다.
4. 대상 사용자(아이)를 가정한 UX 설계와 사용자 테스트를 수행할 수 있다.

### 1.3 시스템 구조

```
〔아이 폰/태블릿〕 블록 편집기 웹앱
   │ /program (JSON, 실행 시 엣지)      ▲ /run_state (엣지: 블록 하이라이트)
   │ /run_stop (엣지: 빨간 정지 버튼)   │
   ▼                                    │
  wss ──── rosbridge_server ────────────┘
   │
   ▼
〔Pi〕 interpreter_node ──/cmd_vel(10Hz 연속)──▶ 터틀봇
   ▲ /obstacle_dist (연속)        └─/buzzer(엣지)──▶ 부저
   └ 초음파 노드
```

### 1.4 조원 역할 (5~6인)

| 역할 | 담당 | 핵심 산출물 |
|---|---|---|
| 🌐 웹 A | 블록 편집기 (드래그/탭 조립) | blocks.html |
| 🌐 웹 B | 실행 UI (하이라이트·정지 버튼·중단 안내) | 편집기 통합 |
| 🤖 ROS | interpreter_node | 인터프리터 + 블록 명세서 |
| 🔩 HW | 초음파 노드, 부저, 실행 코스 | 노드 + 코스 |
| 🎨 UX | 아이 관점 설계·사용자 테스트 설계·진행 | UX 설계서 + 테스트 결과 |
| 🔗 통합·QA (6인) | 인터페이스·테스트 | INTERFACE.md, TEST.md |

💡 UX 역할은 "블록 이름을 아이가 이해하나", "중단됐을 때 무섭지 않게
알려주나" 같은 질문을 담당합니다. 코드가 아니라 관찰과 문서가 산출물입니다.

## 3. 토픽 인터페이스 정의서 (INTERFACE.md 초안)

| 토픽명 | 메시지 타입 | 발행자 | 구독자 | 주기 | 성격 | QoS |
|---|---|---|---|---|---|---|
| /program | std_msgs/msg/String (JSON 배열) | 편집기 | interpreter | 실행 버튼 시 | 엣지 | RELIABLE |
| /run_stop | std_msgs/msg/Bool | 편집기 | interpreter | 정지 버튼 시 | 엣지 | RELIABLE |
| /run_state | std_msgs/msg/String (JSON) | interpreter | 편집기 | 블록 전환·종료 시 | 엣지 | RELIABLE |
| /obstacle_dist | std_msgs/msg/Float32 | 초음파 노드 | interpreter | 10Hz | **연속** | RELIABLE |
| /cmd_vel | geometry_msgs/msg/Twist | interpreter | 터틀봇 | 10Hz | **연속** | RELIABLE |
| /buzzer | std_msgs/msg/Bool | interpreter | buzzer_node | 부저 블록 시 | 엣지 | RELIABLE |

**프로그램 JSON**:
```json
[{"op":"forward","sec":3},{"op":"turn_left"},{"op":"buzzer"},{"op":"wait","sec":1}]
```
**/run_state JSON**: `{"state":"block","op":"forward","left":3}` /
`{"state":"aborted","reason":"장애물 감지"}` / `{"state":"done"}`

> ⚠️ 블록 명세서(op 이름·파라미터·실행 의미)가 웹↔ROS 간 **계약**입니다.
> "왼쪽으로"가 90도인지 계속 도는 것인지 같은 의미 차이가 통합을
> 깨뜨립니다. Day 1에 블록 명세서를 확정하고 INTERFACE.md에 포함하세요.

## 4. 구현 가이드

### 4.1 🌐 블록 편집기

Blockly 라이브러리 전체를 쓰지 않아도 됩니다. **탭으로 블록을 추가하고
드래그로 순서를 바꾸는 리스트 UI**면 충분합니다(초등 저학년은 오히려
이쪽이 쉽습니다). 아이 눈높이 원칙: 큰 버튼(최소 60px), 글자보다 아이콘
(⬆️ ↩️ 🔔 ⏱️), 실행 중 화면 잠금(편집 방지), 밝은 하이라이트.

```javascript
function run() {
  progTopic.publish(new ROSLIB.Message({ data: JSON.stringify(blocks) }));
  lockEditor(true);
}
stateTopic.subscribe((msg) => {
  const s = JSON.parse(msg.data);
  if (s.state === 'block') highlightBlock(s);          // 실행 위치 표시
  if (s.state === 'done') { lockEditor(false); confetti(); }
  if (s.state === 'aborted') showKidFriendly(s.reason); // "앞에 뭔가 있어요!"
});
```

### 4.2 🤖 interpreter_node.py (py_compile 검증 완료)

```python
#!/usr/bin/env python3
"""interpreter_node: 블록 프로그램(JSON) 순차 실행 + 안전 중단"""
import json, time
import rclpy
from rclpy.node import Node
from std_msgs.msg import String, Bool, Float32
from geometry_msgs.msg import Twist

OBSTACLE_M = 0.20
TURN_90_SEC = 3.1      # 90도 회전 시간 (실측 보정)


class InterpreterNode(Node):
    def __init__(self):
        super().__init__('interpreter_node')
        self.sub_prog = self.create_subscription(String, '/program', self.on_program, 10)
        self.sub_stop = self.create_subscription(Bool, '/run_stop', self.on_stop, 10)
        self.sub_dist = self.create_subscription(Float32, '/obstacle_dist', self.on_dist, 10)
        self.pub_vel = self.create_publisher(Twist, '/cmd_vel', 10)
        self.pub_buzzer = self.create_publisher(Bool, '/buzzer', 10)
        self.pub_state = self.create_publisher(String, '/run_state', 10)
        self.program = []        # 남은 블록
        self.remain = 0.0        # 현재 블록 남은 시간
        self.cur = None          # 실행 중 블록
        self.dist = 999.0
        self.timer = self.create_timer(0.1, self.tick)
        self.get_logger().info('interpreter_node 시작')

    def state(self, s, **kw):
        msg = String()
        msg.data = json.dumps({'state': s, **kw}, ensure_ascii=False)
        self.pub_state.publish(msg)      # 엣지: 블록 하이라이트용

    def on_program(self, msg):
        """블록 배열: [{"op":"forward","sec":3},{"op":"turn_left"},
                       {"op":"buzzer"},{"op":"wait","sec":1}]"""
        self.program = json.loads(msg.data)
        self.cur = None
        self.state('running', total=len(self.program))

    def on_stop(self, msg):
        if msg.data:
            self.abort('사용자 중지')

    def on_dist(self, msg):
        self.dist = float(msg.data)

    def abort(self, reason):
        self.program = []
        self.cur = None
        self.state('aborted', reason=reason)

    def next_block(self):
        if not self.program:
            if self.cur is not None:
                self.cur = None
                self.state('done')
            return
        self.cur = self.program.pop(0)
        op = self.cur['op']
        if op == 'forward':
            self.remain = float(self.cur.get('sec', 1))
        elif op in ('turn_left', 'turn_right'):
            self.remain = TURN_90_SEC
        elif op == 'wait':
            self.remain = float(self.cur.get('sec', 1))
        elif op == 'buzzer':
            buz = Bool(); buz.data = True
            self.pub_buzzer.publish(buz)
            self.remain = 0.5
        self.state('block', op=op, left=len(self.program))

    def tick(self):
        cmd = Twist()
        if self.cur is None:
            self.next_block()
        if self.cur is not None:
            op = self.cur['op']
            if op == 'forward':
                if self.dist < OBSTACLE_M:            # 안전 중단
                    self.abort('장애물 감지')
                else:
                    cmd.linear.x = 0.10
            elif op == 'turn_left':
                cmd.angular.z = 0.5
            elif op == 'turn_right':
                cmd.angular.z = -0.5
            self.remain -= 0.1
            if self.remain <= 0:
                self.cur = None
        self.pub_vel.publish(cmd)                     # 10Hz 연속


def main():
    rclpy.init()
    node = InterpreterNode()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
```

> ⚠️ **스타터 코드의 알려진 한계(조가 해결할 것)**
> ① `done` 상태가 다음 프로그램 수신 전까지만 유의미하고, 실행 완료 후
> abort된 프로그램과 구분되는 UI 처리가 필요합니다. ② 반복 블록(S1)이
> 없습니다 — repeat 블록을 어떻게 표현할지(펼쳐서 전송 vs 인터프리터가
> 해석)는 좋은 설계 토론거리입니다. **펼쳐서 전송이 더 단순하고 견고**
> 하다는 것을 발견하는 과정이 학습입니다. ③ 실행 중 새 `/program` 수신
> 시 즉시 교체됩니다 — 실행 중 잠금이 웹에만 있으므로 노드에서도
> 방어하세요(이중 방어). ④ 장애물 중단 후 "치우면 이어서" 기능은 없음 —
> 이어하기 vs 처음부터의 UX 선택을 사용자 테스트로 결정하세요.

## 7. 트러블슈팅

| 증상 | 원인 | 해결 |
|---|---|---|
| 회전이 90도가 안 됨 | TURN_90_SEC 미보정 | 실측 보정 (배터리 만충 기준) |
| 하이라이트가 로봇보다 늦음/빠름 | state 발행 시점 | 블록 시작 시점 발행 확인 |
| 실행 중 편집돼 프로그램 꼬임 | 웹 잠금만 존재 | 알려진 한계 ③ 노드 방어 추가 |
| 장애물 중단이 회전 중엔 안 됨 | forward에서만 검사 | 정책 결정: 회전 중 검사 여부 명시 |
| 부저 블록이 0.5초를 안 지킴 | beep 비동기 | background=True + remain 0.5 유지 |
| 반복 블록 중첩이 꼬임 | 인터프리터 해석 복잡 | 한계 ② — 웹에서 펼쳐 전송 |
| 아이가 정지 버튼을 못 찾음 | UX 문제 | 빨강·크게·항상 같은 위치 (테스트로 검증) |
| done 후 UI 잠김 유지 | 상태 처리 누락 | done/aborted 모두 unlock |
